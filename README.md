# Desempeño de Racks — Imperial

Dashboard Dash + Postgres para analizar desempeño por tienda, pasillo, rack, categoría y SKU, con mapa interactivo, recomendaciones explicables y descargas.

Esta versión prioriza decisiones accionables mientras el margen todavía no está disponible. No presenta “rentabilidad” falsa: usa venta, variación, surtido, stock y venta por SKU.

Consulta **INSTRUCCIONES_V3.md** para:

- qué archivos reemplazar en GitHub,
- cómo actualizar la data desde SQL Server,
- qué filtros/descargas incluye,
- y las consideraciones metodológicas del comparativo histórico por rack.
